# Prompt Master

Turns a rough prompt into a clear, well-structured one before you send it.

- **✨ Prompt Master** button (in the band directly above the prompt box): rewrites whatever you've typed, in place, so you can review it before pressing Enter.
- **↩ Original** restores what you typed.
- **Auto: on/off**: when on, your first Enter polishes the prompt for review, and Enter on the rewrite sends it.
- `/pm <rough prompt>` rewrites text into the box; `/pm-auto` toggles auto mode.

## Install

At the prompt of a Claude Code terminal session:

```
/plugin install prompt-master --marketplace yasserbaghdady/prompt-master
```

Answer `y` to add the marketplace, then pick a scope.

From a shell:

```
claude plugin install prompt-master --marketplace yasserbaghdady/prompt-master
```
